## 2. 프로젝트 배경 및 목적

### 2.1 문제 의식
OTT(온라인동영상서비스) 이용이 확산되면서 미디어 소비 방식이 급격히 변화하고 있습니다. 그러나 "미디어 이용 행태"와 "실제 소비 지출"을 연결해서 분석한 공개 자료는 드뭅니다. 이 두 축을 연결하면 마케팅/소비자 리서치 분야에서 실제로 쓰이는 유형의 인사이트를 도출할 수 있습니다.

본 프로젝트는 서로 다른 두 공공데이터(가계동향조사, 방송매체 이용행태조사)를 세그먼트 단위로 결합하여, 데이터 수집부터 적재·처리·서빙·시각화까지 이어지는 엔드투엔드 파이프라인을 구축하는 것을 목표로 합니다.

### 2.2 분석 가설
> "OTT 이용 강도가 높은 소비자 세그먼트는, 전통 매체 중심 세그먼트와 비교해 소비 지출 패턴(카테고리별 지출 비중)이 다르게 나타날 것이다."

### 2.3 목표
- 서로 다른 출처의 데이터를 정합성 있게 결합하는 파이프라인 설계
- 단순 통계 요약이 아니라, 저장·처리·서빙까지 포함한 시스템 구조로 구현
- 데이터 소스 선정, 한계 검증, 설계 변경 과정을 투명하게 문서화

## 3. 데이터 소스

| 데이터 | 출처 | 수록 기간 | 단위 | 비고 |
|---|---|---|---|---|
| 가계동향조사 (연간, 지출, 신항목분류) | 통계청 MDIS (다운로드 서비스) | 2024~2025 | 가구 단위 원자료 | 지역(시도) 변수 없음, 도시/비도시만 존재 |
| 일주일간 TV수상기 통한 OTT 이용 경험 | 방송매체 이용행태조사 (data.go.kr) | 2024~2025 | 세그먼트 교차표 | 성/연령/지역/직업별 |
| 하루 평균 TV수상기 통한 OTT 이용시간 | 방송매체 이용행태조사 (data.go.kr) | 2024~2025 | 세그먼트 교차표 | 연속형(분) 수치 포함 |
| 스마트폰을 통한 OTT 시청 빈도 | 방송매체 이용행태조사 (data.go.kr) | 2024~2025 | 세그먼트 교차표 | 2024년부터 신설된 항목 (2023 데이터 없음) |

### 3.1 데이터 정합성 관련 의사결정 기록
프로젝트 진행 중 실제로 마주친 데이터 한계와 그에 대한 대응을 아래와 같이 기록합니다.

- **연도 범위 조정**: 스마트폰 기반 OTT 시청 빈도 항목이 2024년부터 신설되어 2023년 데이터가 존재하지 않음을 확인. 4개 데이터셋의 정합성을 위해 분석 기간을 2023~2025년(3개년)에서 **2024~2025년(2개년)으로 축소**.
- **조인 축 제한**: 가계동향조사(공공용/다운로드 서비스)에는 비식별화 정책상 시도 단위 지역 변수가 없고 도시/비도시 구분만 제공됨을 확인. 따라서 원래 계획했던 "지역×연령대" 2축 조인 대신 **"연령대" 단일 축 조인**으로 설계 변경. 도시/비도시 구분은 보조 축으로 활용.
- **연령 형식 불일치 처리**: 가계동향조사는 가구주 연령이 숫자(세)로, 방송매체조사는 연령대 범주(10대~70세 이상)로 제공됨을 확인. 가계동향조사 쪽에서 동일 구간으로 버킷팅하여 조인 키를 통일.
- **인코딩**: 전 CSV 파일이 CP949(EUC-KR)로 인코딩되어 있음을 확인, 전처리 파이프라인에 명시적으로 반영.

## 4. 시스템 아키텍처

```
[데이터 수집]
  가계동향조사 CSV (2024, 2025)
  방송매체 이용행태조사 CSV × 3종 (2024, 2025)
        │
        ▼
[전처리 계층 - Python/Pandas/NumPy]
  - 인코딩 정규화 (CP949 → UTF-8)
  - 다단 헤더 표 → tidy 포맷 변환
  - 가구주 연령 → 연령대 버킷팅
  - 가중값 적용 가중평균 계산
  - 세그먼트 키 표준화 (연령대, 도시/비도시)
        │
        ▼
[저장 계층 - MySQL]
  - segment_dim (세그먼트 차원 테이블)
  - household_spending_agg (가계동향조사 집계)
  - media_usage_agg (미디어 이용행태 집계)
        │
        ▼
[분석 계층]
  - 세그먼트별 교차 분석
  - 상관관계 / 통계 검정
        │
        ▼
[서빙 계층 - FastAPI]
  GET /segments/{id}/summary
  GET /segments/media-spending-correlation
        │
        ▼
[시각화 계층 - Plotly Dash / Streamlit]
  세그먼트별 OTT 이용 강도 × 소비 카테고리 대시보드
```

## 6. 리스크 및 한계 (README에 명시 예정)

- 가계동향조사와 방송매체 이용행태조사는 **서로 다른 표본**을 사용한 조사로, 개인/가구 단위 직접 매칭이 아닌 **세그먼트 단위 집계값 조인**임을 명시
- 지역 변수는 도시/비도시 수준으로만 분석 가능 (시도 단위 분석은 MDIS 인가용 서비스 승인 필요 영역)
- TV수상기 기반 OTT 지표는 모바일 전용 시청자를 포함하지 못하는 한계가 있어, 스마트폰 기반 지표로 일부 보완
